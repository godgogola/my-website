# 代謝症候群（Metabolic Syndrome）

代謝症候群是指身體同時出現多項代謝異常的情形，包括腹部肥胖、高血壓、高血糖、高三酸甘油脂、以及高密度脂蛋白膽固醇（HDL）過低等五項指標。當上述任三項以上異常時，即可診斷為代謝症候群。

這是一種隱形卻危險的健康警訊，會大幅提高心血管疾病、中風、第二型糖尿病及脂肪肝等慢性病的風險。

在診所實地看診下來，有代謝症候群的人不少，這些又被稱為亞健康族群，不趁早發現，不及時改善自己飲食及運動習慣，必定會演變成真正的慢性病。

## 五大判斷指標

| 項目 | 判斷標準 |
|------|----------|
| 腹部肥胖 | 男性腰圍 > 90 cm；女性腰圍 > 80 cm |
| 高血壓 | 收縮壓 ≥ 130 mmHg 或 舒張壓 ≥ 85 mmHg |
| 高血糖 | 空腹血糖 ≥ 100 mg/dL |
| 高三酸甘油脂 | 三酸甘油脂 ≥ 150 mg/dL |
| 高密度脂蛋白膽固醇偏低（HDL） | 男性 < 40 mg/dL；女性 < 50 mg/dL |

> 只要上述五項中有任三項異常，即診斷為代謝症候群。

## 造成原因

造成代謝症候群的主因多與生活型態有關，如：

- 缺乏運動
- 過度攝取油脂與糖分
- 長期壓力
- 抽菸與飲酒

初期往往沒有明顯症狀，卻會在日後演變為嚴重慢性病。

## 三大提醒

- 定期健檢，早期發現高風險族群
- 維持良好生活習慣：運動、均衡飲食、控制體重
- 及早介入可逆轉代謝異常，避免慢性病惡化

**透過調整生活習慣與定期監測指標，即可有效預防與控制代謝症候群。**
