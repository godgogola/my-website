# 懷孕期間腸胃藥物安全指南

懷孕期間，賀爾蒙波動常導致胃酸逆流、孕吐或便秘。為了守護母體與胎兒，了解藥物的安全性分級至關重要。

**安全性指標說明：**
- ✓ 經醫師評估可使用：臨床研究顯示安全性高，為第一線選擇。
- ! 需謹慎評估：通常於一線藥物無效時，經醫師衡量利弊後使用。
- ✕ 建議避免：可能影響子宮收縮或具有潛在風險。

## 二、胃酸、胃灼熱與胃痛

胃食道逆流是孕期常見的困擾，通常建議從溫和的藥物開始：

| 藥物 | 安全性 | 說明 |
|------|--------|------|
| 制酸劑（Al(OH)₃、Mg(OH)₂、CaCO₃） | ✓ | 注意：應避免長期服用含「鈉」高的劑型，以免誘發水腫。 |
| 胃黏膜保護劑（Sucralfate） | ✓ | 不被全身吸收，安全性極高。 |
| H2 抑制劑（H2RAs）：Famotidine | ✓ | 目前首選，安全性證據充足。 |
| 氫離子幫浦阻斷劑（PPI）：Omeprazole、Lansoprazole | ! | 於一線藥物無效時使用。 |

## 三、孕吐管理與止瀉藥物

嚴重的嘔吐可能導致脫水，需及時治療。止瀉方面則以吸附性藥物為主，減少對血液系統的影響：

| 藥物 | 安全性 | 說明 |
|------|--------|------|
| 第一線治療（NVP）：Vitamin B6 搭配 Doxylamine | ✓ | 孕吐首選。 |
| 多巴胺拮抗劑：Metoclopramide（Primperan） | ✓ | 用於中度嘔吐。 |
| 吸附性藥粉：Smecta（天然矽酸黏土） | ✓ | 不進入血液，非常安全。 |
| Loperamide（Imodium） | ! | 嚴重腹瀉時，於中、後期可考慮使用。 |

## 四、便秘藥物建議

孕期便秘是因為腸蠕動減緩所致。首選作用溫和的滲透性緩瀉劑，避免刺激子宮收縮：

| 藥物 | 安全性 | 說明 |
|------|--------|------|
| 乳果糖（Lactulose）或 Macrogol 4000（PEG） | ✓ | 首選。 |
| 氧化鎂（MgO） | ✓ | 兼具制酸與緩瀉作用。 |
| 刺激性瀉劑（Bisacodyl） | ✕ | 可能誘發子宮收縮，非必要不建議使用。 |

## 五、內科顧問的重要叮嚀

1. **藥物交互作用：** 含鈣、鋁、鎂的制酸劑會抑制「鐵劑」吸收。兩者請務必間隔至少 **2 小時**服用。

2. **警訊症狀：** 若出現劇烈腹痛、陰道出血、發燒超過 38°C、血便或嚴重嘔吐（無法進食），請務必立即就醫。

> **顧問結語：** 懷孕期間用藥應遵循「最小有效劑量」與「最短療程」原則。任何藥物使用前，請務必先諮詢您的婦產科或腸胃科醫師。
