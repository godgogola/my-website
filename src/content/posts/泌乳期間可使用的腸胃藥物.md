# 哺乳媽媽：腸胃不適怎麼辦？詳解用藥安全指南

許多哺乳媽媽在遇到腸胃炎、拉肚子或胃痛時，往往選擇「硬扛」，深怕吃藥會透過乳汁影響寶寶。其實，這是一種迷思。媽媽身體不舒服，反而會影響泌乳品質與照顧寶寶的體力。只要選對藥物，哺乳期也能安心治療。

> 🚨 **緊急警訊：何時該立刻就醫？**
> 如果出現以下症狀，請不要只吃成藥，應立即前往急診或門診：
> - 發燒超過 38°C 或嚴重畏寒
> - 糞便帶血（鮮紅色或柏油狀黑便）
> - 持續性的劇烈腹痛（非一陣一陣的絞痛）
> - 脫水徵兆（口乾、尿量大減、暈眩）

## 一、拉肚子怎麼辦？止瀉藥物選擇

腹瀉時最重要的不是止瀉，而是**補充水分**。請優先使用 ORS 補液鹽，預防脫水。

若需要藥物輔助，以下是安全名單：

| 藥物 | 說明 |
|------|------|
| Smecta（舒腹達） | 物理性吸附毒素，完全不進入血液與乳汁，非常安全。 |
| 益生菌（Probiotics） | 如 BioGaia 或 Culturelle，有助恢復腸道菌叢，對寶寶無害。 |
| Loperamide（Imodium） | 短期（24 小時內）使用是可以接受的，分泌至乳汁量極低，但不要長期大量服用。 |

## 二、胃痛、胃食道逆流的用藥建議

半夜餵奶作息不正常，很容易引發胃痛。好消息是，大部分胃藥對哺乳媽媽都是友善的：

| 藥物 | 說明 |
|------|------|
| 制酸劑（胃乳/胃片） | 含有鋁、鎂、鈣的成分（如 MgO），主要在腸胃道局部作用，幾乎不吸收，安全。 |
| Sucralfate（舒克胃） | 在胃黏膜形成保護層，極少被吸收，哺乳期可安心使用。 |
| Famotidine（H2 Blockers） | 這是哺乳期的**首選胃藥**，比 Cimetidine 更安全。 |

> 💡 **關於 PPI（質子幫浦抑制劑）的迷思：**
> 許多藥單上會標示 Omeprazole 等藥物要「慎用」，讓媽媽很緊張。但實證醫學顯示，這類藥物進入乳汁極少，且會被寶寶的胃酸破壞。若有嚴重胃潰瘍，在醫師處方下使用是安全的。

## 三、脹氣與噁心想吐

| 藥物 | 說明 |
|------|------|
| Simethicone（Gascon） | 純粹是物理性消泡，完全不吸收，對寶寶無影響。 |
| 維生素 B6 | 緩解輕微噁心嘔吐的第一線安全選擇。 |
| Metoclopramide（Primperan） | 有效止吐，但因為會促進泌乳且有中樞副作用，建議短期使用就好。 |

## 四、便秘藥物的使用原則

| 藥物 | 說明 |
|------|------|
| Lactulose / PEG 4000 | 高滲透壓瀉劑，人體不吸收，是長期使用的首選。 |
| MgO（氧化鎂） | 既能軟便又能制酸，安全性高。 |
| Bisacodyl（Dulcolax） | 屬於刺激性瀉劑。雖然吸收率極低，但建議作為二線救援（真的拉不出來時）再使用。 |

## 總結與提醒

哺乳雖然辛苦，但媽媽的健康更重要。請避開來路不明的中草藥，以及絕對禁用的化療藥物。

一般的腸胃不適，只要依照上述原則選藥，通常都能在不影響寶寶的情況下緩解症狀。如果您對手邊的藥物有疑慮，建議直接諮詢您的內科醫師或小兒科醫師，讓專業為您把關。
